Welcome to AnimeKai RPC

Alpha 4 makes setup a lot less technical. The Discord application is already included; you only need to allow embedded-player detection and install the small Windows helper.

V6 Alpha 4 • Made by viesca27
1

Discord app is already configured

You do not need a Discord Developer Portal account, bot token, client secret, or Application ID. AnimeKai RPC ships with its public Rich Presence application ID.

✓ Nothing to configure here
2

Enable embedded-player detection

AnimeKai loads video players inside third-party frames. This optional browser permission lets AnimeKai RPC inspect those frames for play, pause, buffering, and timestamps. The detector exits immediately when a frame is not inside an AnimeKai page.

Checking permission…
3

Install the Windows helper

The helper is what talks to the Discord desktop app. If you already installed Alpha 4, this step will show as connected. Otherwise download the Windows package, extract it, and run Install AnimeKai RPC.cmd.

Checking helper…
Why is player access optional? Earlier V6 alphas requested broad frame access as a required install permission. Alpha 4 moves it behind this clear setup step instead. AnimeKai uses changing third-party video hosts, so limiting the permission to a fixed list of player domains would regularly break detection. The extension code still ignores pages and frames that are not part of AnimeKai.
You can reopen this setup guide from the extension popup at any time.
