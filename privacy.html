Privacy

This page describes V6.1.6 and the V7 alpha 1 extension. It will be reviewed again before browser-store submission so the published policy matches the final release exactly.

Overview

AnimeKai RPC is designed around local playback detection and local Discord Rich Presence. The browser extension reads supported anime pages and playback state, then sends the presence information to a small Native Messaging helper on your own computer. The helper talks to the Discord desktop app locally.

Information processed

AnimeKai RPC may process the anime title, episode number, total episode count, playback state, playback position and duration, cover-art URL, the site name, and the watch-page URL. This information is used to build the Rich Presence shown in Discord.

Optional embedded-player access

Supported sites can load video players inside third-party frames. V6 and V7 ask for broad frame access only as an optional permission when the user chooses Enable player detection. V6 checks AnimeKai ancestry. V7 additionally validates the browser frame tree against an approved player iframe on an enabled AnimeKai, AnimePahe, or 9anime page. This access is used for play, pause, buffering, seeking, and timestamp detection inside supported embedded players.

Local settings

Preferences such as appearance, playback options, templates, artwork cache entries, and setup state may be stored locally by the browser extension or desktop helper. The helper also stores the public Discord Application ID used by AnimeKai RPC.

External artwork lookup

If a supported site does not provide a usable cover image, the extension may send the anime title to the Jikan API to look up matching anime metadata and poster artwork. Successful artwork results may be cached locally for a limited period to avoid unnecessary repeat lookups.

V7 sites and guided help

V7 recognizes animekai.be, animepahe.com, and 9animehd.live plus their www variants. Site toggles control presence sharing; the manifest requests all three named sites. The optional player permission is broader because embedded player domains change. The Help & FAQ panel matches written answers locally, does not call an AI service, and does not save question history. Images are loaded from the source sites, cached cover providers, or public GitHub release assets; those services receive the image requests.

Discord

AnimeKai RPC does not require your Discord password, user token, bot token, or client secret. The bundled Discord Application ID is a public Rich Presence identifier and is not an account credential.

Analytics and advertising

The AnimeKai RPC extension and this GitHub Pages site do not include analytics, advertising, or tracking scripts maintained by this project.

Support

Bug reports and support requests can be submitted through the project's GitHub issue tracker. Diagnostics are only copied when you choose Copy diagnostics; AnimeKai RPC does not automatically upload them.
