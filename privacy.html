Privacy

This is a ready-to-edit privacy-policy starter. Before a V6 browser-store submission, update it so it exactly matches the final permissions, network requests, providers, and data handling.

Overview

AnimeKai RPC is designed to run locally. It detects playback context on AnimeKai and sends Rich Presence details to the Discord desktop application through a local Native Messaging helper.

Information processed

The extension may process AnimeKai page titles, episode information, media playback state, playback time, cover-art URLs, and local AnimeKai page URLs as needed to build Rich Presence.

Local settings

User preferences such as appearance, playback options, templates, and diagnostic configuration may be stored locally by the browser extension or desktop helper.

External artwork and metadata

V6 may optionally request anime metadata or cover artwork from third-party data providers when the original cover image is unavailable. The final production policy should name the exact providers used.

No Discord credentials

AnimeKai RPC does not require a Discord password, user token, or bot token. A Discord Application ID is a public identifier, not an account credential.

Analytics

This GitHub Pages starter contains no analytics or tracking scripts.
