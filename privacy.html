Privacy

This page describes the current V6 Alpha 4 behavior. It will be reviewed again before browser-store submission so the published policy matches the final release exactly.

Overview

AnimeKai RPC is designed around local playback detection and local Discord Rich Presence. The browser extension reads the AnimeKai page and playback state, then sends the presence information to a small Native Messaging helper on your own computer. The helper talks to the Discord desktop app locally.

Information processed

AnimeKai RPC may process the anime title, episode number, total episode count, playback state, playback position and duration, cover-art URL, and the AnimeKai watch-page URL. This information is used to build the Rich Presence shown in Discord.

Optional embedded-player access

AnimeKai can load video players inside third-party frames. V6 Alpha 4 asks for broad frame access only as an optional permission when the user chooses Enable player detection. The player detector checks whether a frame is part of an AnimeKai page and exits when it is not. This access is used for play, pause, buffering, seeking, and timestamp detection inside AnimeKai's embedded players.

Local settings

Preferences such as appearance, playback options, templates, artwork cache entries, and setup state may be stored locally by the browser extension or desktop helper. The helper also stores the public Discord Application ID used by AnimeKai RPC.

External artwork lookup

If AnimeKai does not provide a usable cover image, V6 may send the anime title to the Jikan API to look up matching anime metadata and poster artwork. Successful artwork results may be cached locally for a limited period to avoid unnecessary repeat lookups.

Discord

AnimeKai RPC does not require your Discord password, user token, bot token, or client secret. The bundled Discord Application ID is a public Rich Presence identifier and is not an account credential.

Analytics and advertising

The AnimeKai RPC extension and this GitHub Pages site do not include analytics, advertising, or tracking scripts maintained by this project.

Support

Bug reports and support requests can be submitted through the project's GitHub issue tracker. Diagnostics are only copied when you choose Copy diagnostics; AnimeKai RPC does not automatically upload them.
