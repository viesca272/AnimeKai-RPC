Support

If AnimeKai RPC stops working, start with the app's Repair App workflow. It is intended to verify the native helper, Native Messaging registration, browser bridge, Discord desktop connection, and safe local configuration.

Quick checks

  • Make sure the Discord desktop application is running.
  • Make sure the AnimeKai RPC extension is enabled.
  • Open an AnimeKai watch page and start playback.
  • Open the extension popup and check Native Host and Discord RPC diagnostics.
  • Use Copy Diagnostics before filing a support request.

Repair App

V6's repair flow is designed to fix local installation problems without deleting themes or personal settings. Reset Settings remains a separate action.

Still stuck?

Configure a project issue tracker or support URL in site-config.js so users can reach you directly.
