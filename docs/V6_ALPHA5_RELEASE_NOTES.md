# AnimeKai RPC V6 Alpha 5

Alpha 5 is all about making the extension feel more personal without touching the RPC logic that already works.

## What's new

- Added separate color controls for the **accent**, **popup background**, and **card background**.
- Added six premade appearance presets:
  - **AnimeKai** — the familiar purple default
  - **Borealis** — dark teal with a mint accent
  - **Charcoal** — neutral gray and low-key
  - **Midnight** — deep navy with blue highlights
  - **Sakura** — dark pink / plum
  - **Ember** — warm brown with orange highlights
- Presets apply instantly so users can preview the look before closing the popup.
- Manual color changes automatically switch the theme label to **Custom**.
- Added **Reset colors** to return to the default AnimeKai look.
- Appearance choices are stored in the extension's local settings, so they persist between browser sessions and normal helper repairs/reinstalls.
- The existing dark/light/system text-mode selector, compact-layout option, and reduced-motion option are still available.

## Still included from Alpha 4

- Built-in Discord Application ID — no Discord developer setup required.
- V5-style extension icon.
- First-run setup guide.
- Optional third-party player-frame permission instead of requiring `<all_urls>` at install time.
- Desktop-helper version detection and guided updates.
- Refresh / reconnect button.
- Repair App.
- Alternate cover-art lookup and caching.

## Installing Alpha 5

1. Download `AnimeKai-RPC-V6.0.0-alpha.5-Windows.zip`.
2. Extract it somewhere permanent.
3. Run `Install AnimeKai RPC.cmd` so the helper updates to Alpha 5.
4. Remove or disable the older V6 test extension.
5. Load Alpha 5's `extension` folder as an unpacked extension.
6. Enable player detection from the setup page if the browser asks for it.
7. Open AnimeKai and start an episode.

## What to test

Please try all six presets, then make a custom color setup of your own. Close and reopen the popup and make sure the colors stay saved. Also confirm Discord playback detection still behaves exactly like Alpha 4.

V5 remains the stable release while V6 is being tested.
