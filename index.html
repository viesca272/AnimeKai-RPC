Local architecture

Install V6

V6 is the recommended stable build. Browser-store publishing is still being finalized, so the GitHub release currently includes the unpacked extension plus the Windows helper.

Current V6 flow

Download V6

Get the V6.0.0 Windows ZIP from the latest GitHub Release and extract it somewhere permanent.

Install the helper

Run Install AnimeKai RPC.cmd. Existing V5/V6 preferences are preserved.

Load the extension

Until the store listing is live, load the included extension folder from your browser's Extensions page.

Enable Player detection

The setup guide explains and requests optional access for AnimeKai's changing embedded player frames.

Watch

Open AnimeKai and start an episode. Refresh is available if Discord needs a quick reconnect.
