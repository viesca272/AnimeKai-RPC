Built to disappear into the background.

Open AnimeKai, press play, and your presence updates. The technical stuff is there when you need it—not when you don't.

▶

Automatic playback detection

Tracks anime title, episode, play/pause state, progress, and timestamps without manual status editing.

Better cover artwork

One-click Repair App

◉

Theme customization

V6 adds an accent color picker, presets, layout options, reduced motion, and other appearance controls.

⌁

Local architecture

The extension talks to a small Windows Native Messaging helper. No cloud server is required for Discord RPC.

✓

Store-ready direction

V6 is being structured for browser-store distribution while keeping the Windows helper as a separate local install.

Installation

V5 can be sideloaded today. V6's goal is to replace Developer Mode with a normal browser-store install.

Current V5 flow

Download the release

Extract AnimeKai RPC somewhere permanent on Windows.

Run the installer

Install the Native Messaging helper and let the health check verify registration.

Load the extension

Open your browser Extensions page, enable Developer mode, and choose Load unpacked.

Open AnimeKai

Start an episode and AnimeKai RPC takes it from there.

V6 target flow

Install from the browser store

No Developer Mode or Load unpacked for normal users.

Install the desktop helper once

The extension detects when the helper is missing and links to the installer.

Automatic health check

Discord, Native Messaging, browser bridge, and AnimeKai detection get checked automatically.

Watch

Your Discord presence updates while you watch.
