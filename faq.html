Getting started

What is Anime-RPC?

Anime-RPC is the new project name for AnimeKai RPC. It shows your anime title, episode, artwork, and playback state on your Discord profile. The current stable release is V6.1.6; its extension and installer still use the AnimeKai RPC name.

Which sites work right now?

V6.1.6 supports AnimeKai. V7 alpha adds experimental adapters for animepahe.com and 9animehd.live, disabled by default. All three sites still need live V7 playback checks. These adapters are not included in stable V6.

What do I need to use it?

The current package needs Windows 10 or 11, Discord desktop, and a Chromium-based browser such as Chrome, Edge, or Opera. Mobile devices, macOS, Linux, and Firefox are not part of the current supported installation guide.

How do I install it?
  1. Download AnimeKai-RPC-V6.1.6-Windows.zip from the V6.1.6 release.
  2. Extract it into a folder you will keep.
  3. Run Install AnimeKai RPC.cmd.
  4. Open your browser’s Extensions page, enable Developer mode, choose Load unpacked, and select the extracted extension folder.
  5. Finish setup and enable Player detection, then open Discord desktop and start an AnimeKai episode.

See the installation overview or full step-by-step guide.

Do I need Python or a Discord Application ID?

No. The Windows ZIP includes the desktop helper and a public Discord Application ID. You do not need Python, a Discord developer account, or a manually started server. The helper starts when the extension connects.

When something is not working

Why is nothing showing on Discord?

Open Discord desktop and check that the extension and desktop helper are connected. Start an episode on AnimeKai, press Refresh in the extension, and try Run health check. Use Repair App if the check reports an installation problem. Discord in a browser is not enough.

Why does the player say “waiting”?

Check that an episode is actually playing and that Player detection is enabled in the extension setup. If you granted access while the watch page was already open, refresh that page and start playback again. Embedded players can change; if it still says waiting, copy the diagnostics and report the site and episode URL.

Why does it ask for website access?

AnimeKai can embed its video player on a different domain. Optional Player detection access lets the extension read playback state and timing inside those frames. V6 is designed to check that the frame belongs to an AnimeKai page. Without that access, embedded-player detection may not work.

How do I update or repair it?

For an update, download and extract the current Windows ZIP, run its installer, and reload or replace the unpacked extension using the new extension folder. Refresh open AnimeKai tabs. For connection problems, use Run health check and Repair App. Normal repairs are intended to preserve appearance and RPC preferences.

Why are the playback badges black now?

The V6.1.6 soft update changed the play/pause circles from green to black while retaining the white symbols. The release version and playback behavior did not change.

How do I report a problem?

Use Copy diagnostics in the extension, review the text before sharing it, and open a GitHub issue. Include the extension version, browser, site, what happened, and what you expected. Never include passwords or account tokens.

Privacy and what comes next

Does it need my Discord password or token?

No. It uses a public Application ID and the local Discord connection through the helper. It does not need your password or Discord user token. Watching details are sent to Discord, and V6 can contact Jikan to find replacement artwork. Read the privacy information.

Is it available in the extension store?

Store distribution is still in preparation. Use the documented unpacked-extension installation for V6.1.6. Chrome Web Store and Edge Add-ons are part of the V7 plan; a store-installed extension will still need the desktop helper with the current architecture.

What is planned for V7?

V7 plans include the Anime-RPC rebrand, AnimeKai plus AnimePahe and 9animehd.live detection, easier installation, store preparation, and better help. The alpha now includes initial adapters, site controls, artwork, and local guided help. Live verification, repository renaming, and store publication remain pending. Follow the V7 roadmap for milestones and testing requirements.

Is this an AI chatbot?

This page is a straightforward FAQ with written answers. The V7 extension includes a local guided-help panel that matches questions to written FAQ answers. It is not an AI service and does not transmit or save your questions. No chatbot is running on this website.

Still stuck?

Share your browser, extension version, and the issue you’re seeing. Diagnostics from the extension can help narrow it down.
