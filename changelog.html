Changelog

V6.1.6 — playback badges

  • Restored dynamic play and pause badges on the watching Rich Presence.
  • Playing shows a play icon; paused shows a pause icon.
  • Buffering and finished states keep the AnimeKai badge as a neutral fallback.
  • Browsing still uses the clean AnimeKai artwork introduced in V6.1.5.

V6.1.5 — clean artwork rebuild

  • Fixed the browsing image corruption at its source instead of treating it as a Discord crop issue.
  • Rebuilt browsing artwork from a clean AnimeKai icon seed with no alpha/color-key reconstruction.
  • The popup now uses a packaged local PNG, while Discord uses fresh V6.1.5 release URLs to avoid stale cached artwork.
  • Kept the square, 4:3, 16:9, and 2:1 PNG variants.

V6.1.4 — Discord artwork hotfix

  • Replaced the progressive JPEG Rich Presence artwork path with PNG to prevent the black/noise corruption seen in Discord.
  • Changed the default browsing artwork to a padded square image that better matches Discord's current activity thumbnail.
  • Ships square, 4:3, 16:9, and 2:1 PNG artwork at multiple resolutions for fallback/testing.
  • Expanded the README installation guide with a quick-install path and a clear successful-install checklist.

V6.1.3 — crop-safe artwork

  • Added crop-safe AnimeKai browsing artwork in 2:1, 16:9, 4:3, and square layouts.
  • The 2:1 image is now the default for Discord's wide browsing thumbnail, with the other layouts kept as fallbacks.
  • Watching presence keeps the anime cover as the large image and uses the square AnimeKai artwork for small branding.
  • Expanded the README installation guide with Opera, Chrome, Edge, updating, troubleshooting, and uninstall steps.

V6.1.2 — artwork polish

  • Replaced the generic browsing RPC image with the actual AnimeKai artwork.
  • Watching RPC now keeps anime cover art as the large image and adds AnimeKai branding as the small image when Discord accepts it.
  • Added a safe fallback so cover artwork still works if Discord rejects the small branding image.

V6.1.1 — hotfix

  • Fixed a background-service-worker search regex that could trigger status code 15 and invalid regular expression flags.
  • No intended feature changes from V6.1.0.

V6.1.0 — polish release

  • Added an immediate Browsing AnimeKai Discord presence with AnimeKai RPC artwork and browsing time.
  • Added a Searching for something to watch state on search pages.
  • Made detection event-first with document-start loading, route hooks, video events, MutationObserver updates, and short startup bursts.
  • Stopped appearance-only changes from unnecessarily reconfiguring the desktop RPC connection.
  • Expanded Run health check with per-component results for the helper, Native Messaging manifest, browser registration, local configuration, install metadata, Discord application, Discord connection, and Player detection.
  • Updated the desktop helper to 6.1.0 / protocol v3 with browsing support and better installation-health reporting.

V6.0.0 — official stable release

  • Promoted the tested V6 alpha feature set into the official V6 release.
  • Updated the Windows desktop helper to stable 6.0.0 with clearer Discord connection errors, version/channel/protocol reporting, install metadata, and a second initial connection attempt.
  • Converted the six built-in appearance themes into gradient presets: AnimeKai Aurora, Borealis, Charcoal, Midnight, Sakura, and Ember.
  • Kept custom accent, popup background, and card colors for users who prefer a flat custom theme.
  • Kept the bundled Discord Application ID, V5-style browser icon, Refresh button, Repair App, first-run setup, helper-version checks, optional embedded-player permission, and alternate cover-art recovery.
  • V6.0.0 is now the recommended stable GitHub release; V5 remains available as the legacy fallback.

V6 Alpha 5

  • Expanded Appearance with separate accent, popup background, and card color controls.
  • Added the first set of AnimeKai, Borealis, Charcoal, Midnight, Sakura, and Ember presets.

V6 Alpha 4

  • Added first-run setup and helper-version status.
  • Moved broad player-frame access behind an optional user-granted permission.

V6 Alpha 3

  • Bundled the public AnimeKai RPC Discord Application ID.
  • Restored the V5-style purple extension icon.

V5 — legacy stable foundation

V5 established the client-friendly Windows setup, Native Messaging helper, diagnostics, and the stable playback/RPC path carried into V6.
