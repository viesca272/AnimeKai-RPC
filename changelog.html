Changelog

V6 Alpha 4

  • Added a first-run setup page with plain-English checks for player access and the Windows helper.
  • Moved broad third-party player-frame access out of required install permissions and into an optional permission requested only when the user enables full player detection.
  • Added dynamic registration for embedded-player detection after that permission is granted.
  • Added helper version status and direct Install / Update controls to the popup.
  • Kept the built-in Discord Application ID, V5-style extension icon, Refresh button, Repair App, appearance settings, and cover-art recovery from Alpha 3.
  • Updated the privacy page to describe the current V6 behavior more clearly.

V6 Alpha 3

  • Bundled the public AnimeKai RPC Discord Application ID so users no longer need Discord developer setup.
  • Restored the V5-style purple extension icon.
  • Kept the Alpha 2 refresh/reconnect flow.

V5 — stable foundation

Client-friendly Windows setup, Native Messaging helper, diagnostics, shared publisher Discord Application ID support, and a public-release workflow built on the stable playback/RPC core.
