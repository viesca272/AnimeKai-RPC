# AnimeKai RPC

**Made by viesca27**

AnimeKai RPC brings automatic AnimeKai playback details to Discord Rich Presence through a local Windows Native Messaging helper.

The repository is being prepared for the V6 public release, including browser-store distribution, one-click Repair App support, improved cover-art resolution, appearance customization, and a GitHub Pages project site.

## Website

The GitHub Pages site lives in this repository and includes installation guidance, V6 previews, privacy information, support, and the changelog.

## V6 goals

- Browser-store-ready extension distribution
- One-click Repair App
- Theme/accent color customization
- Better alternate cover-art lookup and caching
- Friendlier first-run helper installation
- Store-aware helper/update flow
- Accessibility and reduced-motion controls
